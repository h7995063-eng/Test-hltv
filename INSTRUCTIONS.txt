ИНСТРУКЦИЯ ПО ЗАПУСКУ И ПЕРЕДАЧЕ ПРОЕКТА HLTV MINI APP

1. СОСТАВ ПРОЕКТА
В папке находятся следующие файлы:
- index.html — точка входа, разметка приложения.
- style_v3.css — стили.
- app_v5.js — основная логика (рендер, формы, админка).
- data.js — стартовые демо-данные.
- bot.py — пример запуска Telegram-бота (pyTelegramBotAPI).
- server.py — заглушка Flask для локальных тестов (можно не использовать).
- maps/ — изображения карт.
- logo.webp — логотип.

2. ЛОКАЛЬНЫЙ ЗАПУСК
Для проверки интерфейса без сервера:
- Открыть терминал в папке проекта.
- Выполнить: python -m http.server 8080
- Перейти в браузере по адресу: http://localhost:8080

3. ПОДКЛЮЧЕНИЕ К БЭКЕНДУ
На данный момент приложение работает в демо-режиме (данные хранятся в localStorage браузера). 
Для работы с реальным сервером необходимо:
- Открыть app_v5.js.
- Найти в начале файла строку: const API_URL = "https://...";
- Заменить URL на адрес вашего API.
- Заменить блоки работы с localStorage (в функциях отправки заявок и обработки в админке) на вызовы fetch к вашему серверу.

4. НЕОБХОДИМЫЕ ЭНДПОИНТЫ API
Описание форматов запросов и ответов находится в файле README.md в корне проекта.

5. ЗАПУСК БОТА
- Установить зависимости: pip install pyTelegramBotAPI
- В файле bot.py заменить BOT_TOKEN на токен вашего бота.
- В переменной WEBAPP_URL указать ссылку на размещенный фронтенд.
- Запустить: python bot.py

6. ЗАМЕЧАНИЯ
- Для работы Mini App ссылка WEBAPP_URL должна быть доступна по HTTPS.
- Уведомления игрокам (о статусе заявок) должны отправляться с вашего бэкенда через Telegram Bot API.
- Приложение не требует сборки (vanilla JS), достаточно разместить файлы на любом статическом хостинге.
